# otwaytreecare.com

The published files for otwaytreecare.com, served by GitHub Pages from `main` (custom domain in `CNAME`).

This repo holds **build output only**, so don't edit these files by hand. The source is the `otc-website` project, a static Node build:
1. Edit `src/`.
2. Run `node build.mjs`.
3. Copy `dist/` over this repo. Keep `.git`, `.gitignore`, `.claude/` and this README.

- **Launched:** 27 September 2026. It replaced the GoHighLevel export that used to live here.
- **Rolling back:** revert the "Launch the 2026 rebuild" commit and push. The previous site is intact in the history.
